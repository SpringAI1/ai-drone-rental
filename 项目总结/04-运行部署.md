# 运行与部署指南

## 一、本地开发运行

### 前置条件

- JDK 17+（推荐 JDK 20）
- Node.js 18+（推荐 22.x）
- Maven 3.8+
- Redis（可选，缓存用）

### 1. 启动后端

```bash
cd /Users/chenxi/Desktop/AI-Rental/backend

# 方式一：Maven 直接运行
mvn spring-boot:run

# 方式二：打包后运行
mvn package -DskipTests
```

后端启动后：
- API 地址：http://localhost:8080/api

访问：http://localhost:5173

## 二、生产部署

### 部署架构

```
用户浏览器
    │
    ├── Web 前端 ──→ Vercel（静态托管）
    │
    ├── uniapp H5 ──→ Vercel（静态托管）
    │
    └── 后端 API ──→ 本地 Mac + Cloudflare Tunnel（内网穿透）
                         │
                         └── SQLite 数据库 + uploads/ 图片
```

### 1. 后端部署（Cloudflare Tunnel）

#### 一键启动脚本

```bash
bash /Users/chenxi/Desktop/AI-Rental/start.sh
```

脚本会自动：
1. 检查 Java 环境
2. 检查/构建 JAR 包
3. 检查端口占用
4. 启动 Spring Boot（端口 8081）
5. 启动 Cloudflare Tunnel
6. 输出公网访问地址

#### 注意事项

- **Tunnel URL 每次重启会变**，需要更新 Vercel 环境变量
- **Clash Verge TUN 模式会干扰 cloudflared**，需关闭 TUN 模式或退出 Clash
- 后端日志：/tmp/backend.log
- Tunnel 日志：/tmp/cloudflared.log

#### 手动启动

```bash
# 启动后端
cd /Users/chenxi/Desktop/AI-Rental/backend
java -jar target/drone-rental-1.0.0.jar \
  --server.port=8081 \
  --cors.allowed-origins="https://你的前端域名"

# 启动 Tunnel
cloudflared tunnel --url http://localhost:8081
```

### 2. Web 前端部署（Vercel）

```bash
cd /Users/chenxi/Desktop/AI-Rental/frontend-web

# 部署到 Vercel
vercel --prod
```

#### 环境变量配置

在 Vercel 项目设置中添加：

| 变量名 | 值 | 说明 |
|--------|-----|------|
| `VITE_API_BASE_URL` | `https://xxx.trycloudflare.com/api` | 后端 API 地址 |

#### vercel.json 配置

```json
{
  "rewrites": {
    "source": "/(.*)",
    "destination": "/index.html"
  }
}
```

### 3. uniapp H5 部署（Vercel）

```bash
cd /Users/chenxi/Desktop/AI-Rental/frontend-uniapp

# 部署到 Vercel
vercel --prod
```

#### 环境变量

同 Web 前端：`VITE_API_BASE_URL`

## 三、CORS 配置

后端 CORS 白名单（通过启动参数注入）：

```bash
--cors.allowed-origins="http://localhost:5173,http://localhost:5174,http://localhost:3000,http://localhost:8080,https://frontend-web-umber-six.vercel.app,https://frontend-uniapp.vercel.app"
```

新增前端域名时需要：
1. 修改 start.sh 中的 CORS_ORIGINS
2. 重启后端

## 四、数据库管理

```bash
# 查看所有表
```

## 六、常见问题

### 1. 后端启动失败

**端口被占**：
```bash
lsof -i:8081
kill -9 <PID>
```

**数据库找不到表**：确保在 `backend/` 目录下启动（工作目录必须是 backend）

### 2. Tunnel 连接失败

- 检查 Clash Verge 是否开启 TUN 模式（需关闭）
- 检查网络连接
- 查看 /tmp/cloudflared.log

### 3. 前端图片不显示

- 检查 Vercel 环境变量 `VITE_API_BASE_URL` 是否正确
- 检查后端是否正常运行
- 浏览器控制台查看图片请求 URL

### 4. CORS 错误

- 检查后端 CORS 白名单是否包含前端域名
- 修改 start.sh 中的 CORS_ORIGINS
- 重启后端

### 5. 管理员头像丢失

数据库 `user.avatar` 字段为空，需要在个人中心重新上传头像。
