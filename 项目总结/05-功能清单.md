## 三、安全功能

- [x] JWT 认证（24小时有效期）
- [x] BCrypt 密码哈希
- [x] 管理员权限拦截（/admin/**）
- [x] 登录限流（IP 维度，60秒/10次，封禁5分钟）
- [x] CORS 白名单
- [x] RSA+AES 请求加密（信封加密）
- [x] 文件上传安全（扩展名+MIME 双校验）
- [x] SQL 注入防护（参数化查询）
- [x] 路径穿越防护
- [x] 业务越权防护（订单归属校验）
