## 三、功能模块清单

### 1. 认证模块（AuthController `/auth`）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/auth/register` | POST | 用户注册（密码≥6位+字母数字） |
| `/auth/login` | POST | 用户登录（拒绝管理员账号，IP 限流） |
| `/auth/admin/login` | POST | 管理员登录（仅 role=1） |
| `/auth/logout` | POST | 退出登录 |

**关键逻辑**：
- 用户登录接口会拒绝 `role=1` 的管理员账号，提示"此账号为管理员，请使用管理端登录"
- 管理员登录接口会拒绝 `role=0` 的普通用户，提示"无管理员权限"
- 密码支持 BCrypt 和旧 MD5（自动迁移）

## 五、安全特性

### 1. JWT 认证
- 算法：HMAC-SHA
- Claims：userId、username、role
- 有效期：24 小时
- 拦截器：JwtInterceptor 拦截 `/**`，排除公开接口

### 2. 管理员权限
- AdminInterceptor 拦截 `/admin/**`，校验 role=1

### 3. 密码安全
- BCrypt 哈希（spring-security-crypto）
- 兼容旧 MD5（自动迁移）
- 密码复杂度：≥6 位 + 字母 + 数字

### 4. 登录限流
- 按 IP 限流，60 秒内最多 10 次尝试
- 超限封禁 5 分钟
- 支持 X-Forwarded-For 代理透传

### 5. CORS 跨域
- 精确白名单（非 `*`），支持 credentials
- 允许方法：GET/POST/PUT/DELETE/PATCH/OPTIONS
- 白名单：localhost:5173/5174/3000/8080/8081 + Vercel 域名

### 6. 文件上传安全
- 扩展名白名单（仅图片）
- MIME 双重校验
- UUID 重命名 + 路径穿越防护
- 10MB 限制

### 7. SQL 注入防护
- MyBatis-Plus 参数化查询
- 分页插件替代 `LIMIT`
- limit 参数范围校验（1-100）

### 8. 业务越权防护
- 订单查询校验归属
- AI 工具校验订单归属

## 六、特色功能详解

### 1. RSA+AES 混合加密（信封加密）

流程：
1. 后端启动生成 RSA-2048 密钥对，`GET /public/rsa-key` 下发公钥
2. 前端随机生成 AES-256 密钥，用 AES-CBC 加密请求参数
3. 前端用 RSA 公钥加密 AES 密钥
4. 后端 EncryptionFilter 先用 RSA 私钥解 AES 密钥，再用 AES 解密请求
5. 响应用同一 AES 密钥加密返回

### 2. AI RAG 知识库

- 启动时自动加载 `classpath:knowledge-base/*.txt`（4 个文档）
- TokenTextSplitter 切块（300 token，50 重叠）
- 通义千问 text-embedding-v3 向量化（1024 维）
- 自实现 SimpleVectorStore（内存版，持久化到 SQLite）
- 支持 PDF/Word/PPT/Excel 上传（Tika 解析）
- QuestionAnswerAdvisor 注入检索结果到 Prompt

### 3. WebSocket 实时通知

- 端点：`/ws/orders`
- JWT 鉴权（仅管理员）
- 心跳 ping/pong
- ConcurrentHashMap 管理在线管理员会话

### 4. MCP Server

- 端点：`/api/mcp/sse`（SSE Transport）
- 把 9 个 @Tool 业务工具暴露为 MCP 协议
- Claude Desktop / Cursor 可直接调用

### 5. SSE 流式对话

- `POST /ai/v3/chat/stream`
- `text/event-stream` 响应
- `[DONE]` 结束标记
- 防 nginx 代理缓冲（`X-Accel-Buffering: no`）

### 6. 缓存策略

- Redis + Spring Cache
- @Cacheable：dashboardStats、popularDrones、droneList、droneDetail 等
- @CacheEvict：写操作自动清理缓存
