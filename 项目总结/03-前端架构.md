### 路由守卫逻辑

```js
// 1. 已登录访问 guest 页（登录/注册）→ 按角色跳转
if (to.meta.guest && authStore.isLoggedIn) {
  return next(authStore.isAdmin ? '/admin' : '/')
}

// 2. 需登录但未登录 → 跳转登录页
if (to.meta.requireAuth && !authStore.isLoggedIn) {
  return next({ path: '/login', query: { redirect: to.fullPath } })
}

// 3. 需管理员权限但非管理员 → 拒绝
if (to.meta.requireAdmin && !authStore.isAdmin) {
  return next('/')
}

// 4. 管理员不能访问用户页面 → 自动跳回管理后台
if (authStore.isAdmin && to.meta.requireAuth && !to.meta.requireAdmin) {
  return next('/admin')
}
```

### 路由元信息

| 字段 | 说明 |
|------|------|
| `title` | 页面标题 |
| `requireAuth` | 是否需要登录 |
| `requireAdmin` | 是否需要管理员权限 |
| `guest` | 仅游客可访问 |

## 五、图片 URL 处理机制

两端都使用环境变量 `VITE_API_BASE_URL` 拼接后端图片地址：

**Web 端**（utils/helpers.js）：
```js
const API_BASE = import.meta.env.VITE_API_BASE_URL || '/api'
export function getImageUrl(url) {
  if (!url) return ''
  if (url.startsWith('http')) return url
  if (url.startsWith('/api/uploads/')) return url
  if (url.startsWith('/uploads/')) return API_BASE + url
  return API_BASE + (url.startsWith('/') ? '' : '/') + url
}
```

**uniapp 端**（utils/image.ts）：
```typescript
// H5 端优先用环境变量，否则走后端 8080
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL
  ? import.meta.env.VITE_API_BASE_URL.replace(/\/api$/, '')
  : 'http://localhost:8080'
```
