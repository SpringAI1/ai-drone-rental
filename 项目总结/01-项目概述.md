# AI 无人机租赁系统 - 项目概述

## 项目简介

本项目是一个**专业无人机设备租赁服务平台**，提供各类无人机设备的在线租赁服务，涵盖航拍、测绘、农业、巡检等多种应用场景。系统采用前后端分离架构，包含 Web 端（PC 浏览器）、移动端（H5 + 微信小程序）和后端 API 三个子项目。

## 技术栈总览

### 后端
- **框架**：Spring Boot 3.2.5 + Java 17
- **ORM**：MyBatis-Plus 3.5.7
- **数据库**：SQLite 3.46（默认）/ MySQL 8.0（备用）
- **连接池**：Druid 1.2.23
- **缓存**：Redis + Spring Cache
- **认证**：JWT (JJWT 0.12.5) + BCrypt 密码哈希
- **AI**：Spring AI 1.0.0-M8 + 通义千问（DashScope）
- **API 文档**：SpringDoc OpenAPI 2.5.0（Swagger UI）
- **实时通信**：Spring WebSocket
- **构建工具**：Maven

### Web 前端
- **框架**：Vue 3.4.21（组合式 API）
- **构建**：Vite 5.2.0
- **UI 库**：Element Plus 2.6.1
- **状态管理**：Pinia 2.1.7
- **路由**：Vue Router 4.3.0
- **HTTP**：Axios 1.6.8
- **图表**：ECharts 6.0.0
- **加密**：crypto-js + jsencrypt
- **样式**：SCSS

### 移动端（uni-app）
- **框架**：Vue 3.3.13 + uni-app 3.0
- **构建**：Vite 4.4.0
- **状态管理**：Pinia 2.1.7
- **目标平台**：H5 + 微信小程序
- **语言**：TypeScript
- **加密**：crypto-js + jsencrypt

## 核心特色

1. **AI 智能客服**：基于 Spring AI + 通义千问，支持 RAG 知识库检索、Function Calling 工具调用、SSE 流式对话
2. **RSA+AES 加密**：请求响应全链路加密，防止数据中间人窃听
3. **实时通知**：WebSocket 推送订单、评论、故障等事件给管理员
4. **三端覆盖**：Web + H5 + 微信小程序，一套代码多端运行
5. **完整业务闭环**：从浏览、下单、支付、发货、收货、归还到评价的全流程
