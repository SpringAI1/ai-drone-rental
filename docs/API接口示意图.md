## 二、认证流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           用户认证流程                                    │
└─────────────────────────────────────────────────────────────────────────┘

[用户端]                                              [服务端]
    │                                                      │
    │  1. 输入用户名/密码                                   │
    │  ─────────────────────────────────────────────────►  │
    │                                                      │
    │  2. 验证用户名密码                                    │
    │     (使用BCryptPasswordEncoder)                       │
    │                                                      │
    │  3. 生成JWT Token                                    │
    │     Payload: {userId, username, role, exp, iat}      │
    │                                                      │
    │  4. 返回Token                                         │
    │  ◄─────────────────────────────────────────────────  │
    │     {                                                │
    │       "code": 200,                                   │
    │       "data": {                                      │
    │         "token": "eyJhbGciOiJIUzI1NiJ9...",          │
    │         "userId": 1,                                 │
    │         "role": 1                                    │
    │       }                                              │
    │     }                                                │
    │                                                      │
    │  5. 保存Token到本地存储                               │
    │     localStorage / uni.setStorage                    │
    │                                                      │
    │  ─────────────────────────────────────────────────►  │
    │  后续请求携带:                                        │
    │  Header: {                                           │
    │    "Authorization": "Bearer eyJhbGci..."             │
    │  }                                                    │
    │                                                      │
    │  6. 验证Token + 权限检查                               │
    │     - 检查Token是否有效                               │
    │     - 检查Token是否过期                               │
    │     - 检查用户权限是否足够                             │
    │                                                      │
    │  7. 返回业务数据 / 错误                                │
    │  ◄─────────────────────────────────────────────────  │
    │     { "code": 200, "data": {...} }                   │
    │     或                                                │
    │     { "code": 401, "message": "Token已过期" }        │
    │     或                                                │
    │     { "code": 403, "message": "权限不足" }            │


┌─────────────────────────────────────────────────────────────────────────┐
│                           Token过期处理流程                               │
└─────────────────────────────────────────────────────────────────────────┘

[客户端]                                              [服务端]
    │                                                      │
    │  发起请求                                            │
    │  ─────────────────────────────────────────────────►  │
    │                                                      │
    │  Token过期 (exp < currentTime)                        │
    │                                                      │
    │  返回 401                                            │
    │  ◄─────────────────────────────────────────────────  │
    │     { "code": 401, "message": "Token已过期" }        │
    │                                                      │
    │  跳转登录页                                          │
    │  (uni.redirectTo / wx.redirectTo)                    │
    │                                                      │
    │  用户重新登录                                        │
    │  ─────────────────────────────────────────────────►  │
```

## 九、多端数据同步策略

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          多端数据同步策略                                 │
└─────────────────────────────────────────────────────────────────────────┘

┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   Web端      │    │   App端      │    │   小程序端    │
│  Vue + Vuex  │    │  UniApp     │    │  原生/UniApp │
└──────┬───────┘    └──────┬───────┘    └──────┬───────┘
       │                    │                    │
       │                    │                    │
       └────────────────────┼────────────────────┘
                            │
                            ▼
                   ┌──────────────────┐
                   │   共享后端 API    │
                   │                   │
                   │ /user/info        │
                   │ /user/orders     │
                   │ /notification/*  │
                   │ /drone/*         │
                   │      ...         │
                   └────────┬─────────┘
                            │
                            ▼
                   ┌──────────────────┐
                   │   MySQL 数据库    │
                   │                   │
                   │   单一数据源       │
                   └──────────────────┘


数据一致性保证：
─────────────────────────────────────────────────────────────
│   策略      │              说明                            │
─────────────────────────────────────────────────────────────
│ 乐观锁     │ 更新订单时检查 version 字段，防止并发冲突       │
│ 事务保证   │ 订单支付、库存扣减在同一事务中执行             │
│ 幂等性    │ 支付等操作支持幂等，防止重复提交               │
│ 软删除    │ 数据不真正删除，通过 deleted 字段标记          │
└─────────────────────────────────────────────────────────────


Token 存储策略：
─────────────────────────────────────────────────────────────
│   端      │         存储位置         │        安全说明       │
─────────────────────────────────────────────────────────────
│ Web端     │ localStorage / Vuex     │ 容易被XSS攻击获取     │
│ App端     │ uni.setStorage (加密)   │ 比Web端相对安全        │
```
