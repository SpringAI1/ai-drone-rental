# 无人机租赁系统 - 项目分析报告

## 一、项目概述

本项目是一个基于 **Spring Boot 3** + **Vue 3** 的无人机租赁管理系统，提供无人机租赁、订单管理、资质审核、故障报修等核心功能，并集成了 AI 智能助手提供咨询服务。

## 六、安全性

### 6.1 认证机制

- **JWT Token**：用户登录后获取Token，后续请求通过Authorization头携带
- **双角色认证**：普通用户和管理员使用不同的登录接口和拦截器
- **Token过期处理**：前端自动刷新或跳转登录页

### 6.2 访问控制

| 拦截器 | 路径 | 说明 |
|--------|------|------|
| AdminInterceptor | `/api/admin/**` | 管理员权限校验 |
| JwtInterceptor | `/api/user/**`, `/api/order/**` | 用户权限校验 |

### 6.3 数据安全

- 密码使用BCrypt加密存储
- SQL注入防护（MyBatis-Plus参数化查询）
- XSS防护（前端输入过滤）
- 文件上传限制（类型、大小）

#### 9.1.2 AI状态缓存

**问题**：每次请求都查询数据库，性能较差

**优化方案**：使用 Redis 缓存 AI 状态配置

```java
@Override
public boolean getAiStatus() {
    String cacheKey = "ai:status:enabled";
    Boolean cached = redisTemplate.opsForValue().get(cacheKey);
    if (cached != null) {
        return cached;
    }
    AiConfig config = getByKey(AI_STATUS_KEY);
    boolean result = config == null || "true".equals(config.getConfigValue());
    redisTemplate.opsForValue().set(cacheKey, result, 5, TimeUnit.MINUTES);
    return result;
}

@Override
public void setAiStatus(boolean enabled) {
    // 更新数据库...
    redisTemplate.delete("ai:status:enabled");
    redisTemplate.delete("ai:status:maintenanceMessage");
}
```

#### 9.1.3 异常处理增强

**问题**：AI聊天接口异常处理过于简单

**优化方案**：增加详细的异常分类和错误日志

```java
@PostMapping("/chat")
public Result<Map<String, String>> chat(@RequestBody Map<String, String> request) {
    try {
        // ...业务逻辑
```

### 9.2 前端优化

#### 9.2.1 图片懒加载

**问题**：大量图片同时加载影响性能

**优化方案**：使用 Vue 3 的 `IntersectionObserver` 实现懒加载

```javascript
import { ref, onMounted, onUnmounted } from 'vue'

const useLazyLoad = () => {
  const observer = ref(null)
  
  onMounted(() => {
    observer.value = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          const img = entry.target
          img.src = img.dataset.src
          observer.value.unobserve(img)
        }
      })
    })
  })
  
  const observe = (el) => {
    if (observer.value && el) {
      observer.value.observe(el)
    }
  }
  
  onUnmounted(() => {
    observer.value?.disconnect()
  })
  
  return { observe }
}
```

#### 9.3.2 分布式锁

**场景**：高并发下单时防止库存超卖

**方案**：使用 Redis 分布式锁

```java
@Override
@Transactional
public void createOrder(OrderCreateDTO dto) {
    String lockKey = "drone:lock:" + dto.getDroneId();
    Boolean locked = redisTemplate.opsForValue().setIfAbsent(lockKey, "1", 30, TimeUnit.SECONDS);
    
    if (!locked) {
        throw new BusinessException("当前下单人数过多，请稍后重试");
    }
    
    try {
        Drone drone = droneMapper.selectById(dto.getDroneId());
        if (drone.getStock() <= 0) {
            throw new BusinessException("库存不足");
        }
        drone.setStock(drone.getStock() - 1);
        droneMapper.updateById(drone);
        
        // 创建订单...
    } finally {
        redisTemplate.delete(lockKey);
    }
}
```

#### 9.3.3 接口限流

**场景**：防止恶意请求或突发流量冲击

**方案**：使用 Bucket4j 或 Redis 实现限流

```java
@Aspect
@Component
public class RateLimitAspect {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Around("@annotation(com.drone.rental.annotation.RateLimit)")
    public Object rateLimit(ProceedingJoinPoint joinPoint) throws Throwable {
        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        RateLimit annotation = signature.getMethod().getAnnotation(RateLimit.class);
        
        String key = "rate:limit:" + annotation.key();
        String value = redisTemplate.opsForValue().get(key);
        
        if (value != null && Integer.parseInt(value) >= annotation.max()) {
            throw new BusinessException("请求过于频繁，请稍后重试");
        }
        
        redisTemplate.opsForValue().increment(key);
        redisTemplate.expire(key, annotation.seconds(), TimeUnit.SECONDS);
        
        return joinPoint.proceed();
    }
}
```
