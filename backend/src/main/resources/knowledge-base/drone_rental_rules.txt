# 无人机租赁规则

## 1. 租赁流程

### 1.1 用户注册与认证
- 用户需完成实名认证，提供有效身份证件
- 企业用户需提供营业执照副本
- 需通过无人机操作资质审核（如AOPA证书）
- 首次租赁需完成在线安全培训课程

### 1.2 租赁申请
- 选择所需无人机型号及租赁时长
- 确认租赁费用及押金金额
- 签署电子租赁协议
- 支付租赁费用及押金

### 1.3 设备领取
- 到指定门店领取设备或选择快递配送
- 核对设备完整性及配件清单
- 签署设备交接单
- 获取设备操作手册及安全指南

### 1.4 使用期间
- 严格按照操作手册使用设备
- 禁止超出设备性能范围使用
- 定期检查设备状态
- 及时报告任何异常情况

### 1.5 设备归还
- 按约定时间归还设备
- 配合工作人员进行设备检查
- 确认无损坏后退还押金
- 如有损坏需按协议赔偿

## 2. 费用标准

### 2.1 租赁费用
- DJI Mavic 3 系列：299-1299元/天
- DJI Mini 系列：149-599元/天
- DJI Air 系列：199-799元/天
- DJI Inspire 系列：599-2999元/天
- DJI Phantom 系列：899元/天
- DJI Agras 农业系列：899元/天

### 2.2 押金标准
- 消费级无人机：设备价值的30%
- 专业级无人机：设备价值的50%
- 企业级无人机：设备价值的70%

### 2.3 附加费用
- 超时归还：按日租金的150%收取
- 配件损坏：按配件原价收取
- 设备损坏：按维修成本或设备价值收取
- 快递配送：根据距离收取运费

## 3. 保险与赔偿

### 3.1 基础保险
- 所有租赁设备均含基础意外险
- 覆盖设备意外损坏（非人为）
- 最高赔付额度为设备价值的80%

### 3.2 全额保险（可选）
- 费率为日租金的20%
- 覆盖人为操作失误导致的损坏
- 最高赔付额度为设备价值的100%

### 3.3 赔偿标准
- 人为损坏未购买保险：全额赔偿
- 自然损坏：无需赔偿
- 丢失设备：按设备价值赔偿

## 4. 禁止行为

### 4.1 严禁操作
- 在禁飞区域飞行
- 超高飞行（超过120米）
- 夜间无照明飞行
- 超视距飞行（无辅助设备）
- 携带危险物品飞行
- 干扰其他航空器

### 4.2 违规处罚
- 第一次违规：警告并记录
- 第二次违规：暂停租赁资格30天
- 第三次违规：永久取消租赁资格
- 严重违规：移交相关部门处理

## 5. 特殊条款

### 5.1 天气因素
- 大雨、大风（超过6级）天气禁止飞行
- 因天气原因无法使用可申请延期
- 延期需提前24小时申请

### 5.2 设备故障
- 设备故障及时联系客服
- 可申请更换同型号设备
- 故障期间不计入租赁时长

### 5.3 紧急情况
- 设备丢失立即报警并通知平台
- 紧急降落需确保安全区域
- 事故发生后保留现场证据
